# Почему дети часами смотрят блогеров

Редакционный лендинг VK Видео Детям × НЭН о популярных детских блогерах и комментариях психолога.

[Открыть сайт](https://vk-detyam-blogery.nancykhacha1981.chatgpt.site/)

Сайт статический: разметка и текст находятся в `dist/index.html`, стили — в `dist/styles.css`, изображения и шрифты — в `dist/assets/`.

Для локального просмотра:

```sh
python3 -m http.server 8765 --directory dist
```
